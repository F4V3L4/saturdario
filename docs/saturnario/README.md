# Saturnário

Projeto de investigação para construir uma base privada de conhecimento verificável e, posteriormente, um manual de vida sem misticismo.

## Separação importante
- **Aplicação pública:** código, metodologia geral e documentação não sensível.
- **Banco privado:** registros de pesquisa, fontes anotadas, notas pessoais e histórico de análise. Não versionar nem publicar.
- **Manual:** somente princípios revisados; cada princípio deve apontar para alegações e fontes.
